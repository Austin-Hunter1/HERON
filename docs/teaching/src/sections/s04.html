Codes and correlation: many satellites, one frequency

{{MIN}} MIN · CDMA, PROCESSING GAIN, AMBIGUITY

In the forest each tower had its own tone. GNSS does it differently. Every GPS satellite sends on the same frequency, and each one has a different ±1 code. A code matches itself very well, and it matches every other code very badly. That one property separates the satellites, gives range, and pulls the signal out of the noise.

Auto- and cross-correlation

$$R_{AB}(k)=\frac{1}{N}\sum_{n=0}^{N-1} c_A[n]\;c_B[(n+k)\bmod N],\qquad N=1023$$
\(R_{AA}(0)=1\). All other values of a Gold code stay at \(-1/N\), \(-65/N\) or \(+63/N\): at most −24 dB.
  • Range: the lag of the peak is the code delay. One chip is 293 m.
  • Identity: the replica of PRN A finds nothing in PRN B (bottom plot).
  • Ambiguity: the code repeats every 1 ms, so the peak repeats every 1023 chips = 300 km. Correlation gives range modulo 300 km. The data bits and the time stamp remove this ambiguity (Part 05).

Finding a signal below the noise

Lower the input SNR to −20 dB. You cannot see the code in the samples any more, but the correlation peak is still clear. Each chip adds the signal coherently. The noise adds randomly. So the sum of \(N\) chips gains a factor \(N\) in SNR.

$$\text{SNR}_\text{out}=\text{SNR}_\text{in}+10\log_{10}(N\,K)\;\text{dB}$$
\(N=1023\) chips per ms, \(K\) = ms summed coherently. One ms gives 30.1 dB. Input SNR per chip relates to carrier-to-noise density by \(C/N_0=\text{SNR}_\text{chip}+10\log_{10}(1.023\,\text{MHz})\).

In real receivers we do not loop over each lag. A circular correlation is a product in the frequency domain:

$$R=\mathcal{F}^{-1}\!\left\{\mathcal{F}\{x\}\cdot\mathcal{F}\{c\}^{*}\right\}$$
Direct: \(M^2\) multiplies for \(M\) samples. FFT: about \(3M\log_2 M\). For \(M=5000\) samples (1 ms at 5 MS/s): 25 million vs. 0.18 million, for each Doppler bin.

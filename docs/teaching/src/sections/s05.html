From navigation message to position fix

{{MIN}} MIN · TIME TAGS, EPHEMERIS, LEAST SQUARES

Correlation gives the code delay only modulo one code period. The navigation message gives the rest: a time stamp, the satellite orbit, and the satellite clock. Here is the path from tracked code phase to a fix.

Count bits, codes and chips

The message stamps the start of each subframe with the time of week \(t_b\). The receiver then counts down the hierarchy: which bit, which code period inside the bit, and which chip inside the code.

$$t_{tx}=t_b+(N-1)\,20\,\text{ms}+(M-1)\,1\,\text{ms}+\tau$$
\(N\): bit in the subframe (1 to 300). \(M\): code period in the bit (1 to 20). \(\tau\): code phase from tracking. Eq. 15.1

Bit sync finds \(M\). Frame sync (the preamble) finds \(N\) and \(t_b\). Tracking finds \(\tau\) continuously. Without bit and frame sync you know \(t_{tx}\) only modulo 1 ms, which is the 300 km ambiguity of Part 04.

Step

Tracking gives a fraction of a millisecond

For each satellite the DLL reports the code phase \(\tau_i\in[0,1)\) ms. The integer part of the travel time is still unknown. All satellites show a value between 0 and 1 ms.

The message gives the whole number

Bit sync and frame sync give \(N\), \(M\) and \(t_b\), so the receiver knows the full transmit time. GPS travel times are 65 to 90 ms, so the integer part adds 65 to 89 ms.

$$t_{tx}=t_b+(N-1)\,20\,\text{ms}+(M-1)\,1\,\text{ms}+\tau$$
\(t_b\) and \(N\) come from frame sync, \(M\) from bit sync, \(\tau\) from the DLL. Eq. 15.1

Pseudorange

$$\rho_i=c\,\big(t_{rx}-t_{tx,i}\big)$$
\(t_{rx}\) is read from the receiver clock, so \(\rho_i\) contains \(c\,\delta t_u\). That is why we call it a pseudorange.

Place the satellites

The ephemeris is a set of Kepler elements plus small correction terms, valid for about 4 hours. The receiver evaluates them at \(t_{tx}\), not at \(t_{rx}\).

$$M=M_0+n\,(t_{tx}-t_{oe}),\quad E-e\sin E=M,\quad r=a(1-e\cos E)$$
Then rotate by \(\omega\), \(i\) and \(\Omega\) into ECEF. Correct for Earth rotation during the 70 ms travel time (up to about 30 m).

Place the receiver

$$\delta\boldsymbol\rho=\mathbf G\,\delta\mathbf x,\qquad \mathbf G=\begin{bmatrix}-\hat{\mathbf u}_1^{T}&1\\ \vdots&\vdots\\ -\hat{\mathbf u}_n^{T}&1\end{bmatrix},\qquad \delta\mathbf x=(\mathbf G^{T}\mathbf G)^{-1}\mathbf G^{T}\delta\boldsymbol\rho$$
Start at the centre of the Earth. Iterate. It converges in 4 to 6 steps. \(\text{GDOP}=\sqrt{\operatorname{tr}(\mathbf G^{T}\mathbf G)^{-1}}\) scales range error into position error.

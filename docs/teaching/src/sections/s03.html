The signal: carrier × code × data

{{MIN}} MIN · THREE LAYERS, THREE TIME SCALES

A GNSS signal has three layers multiplied together. A fast carrier puts the signal at the RF frequency, a medium-rate code gives each satellite its identity and gives range, and a slow data stream carries the navigation message. Zoom from nanoseconds to tens of milliseconds to see each layer.

HERONFor all demonstrations we use the two HERON bands: L1 at 1575.42 MHz (GPS L1 C/A, L1C, Galileo E1, BeiDou B1C) and L5 at 1176.45 MHz (GPS L5, Galileo E5a, BeiDou B2a).
GPS L1 C/A, PRN 1

Multiply the layers

$$s_{L1}(t)=\sqrt{2P}\;D(t)\;C(t)\;\cos\!\left(2\pi f_{L1}t+\theta\right)$$
\(D\): navigation data (±1, 50 bit/s). \(C\): C/A code (±1, 1.023 Mchip/s, 1023 chips, 1 ms). \(f_{L1}=154\,f_0\), with \(f_0=10.23\) MHz.
$$s_{L5}(t)=\sqrt{2P}\big[D\,N\!H_{10}\,C_I\cos(2\pi f_{L5}t)-N\!H_{20}\,C_Q\sin(2\pi f_{L5}t)\big]$$
L5 has a data channel (I) and a data-free pilot channel (Q), 90° apart. Codes run at 10.23 Mchip/s. Neuman-Hofman overlay codes \(N\!H_{10}\), \(N\!H_{20}\) extend the 1 ms code. \(f_{L5}=115\,f_0\).

Multiplying by ±1 flips the carrier phase by 180°. That is binary phase shift keying (BPSK). Zoom to about 2 µs and look for the phase flips on the bottom trace.

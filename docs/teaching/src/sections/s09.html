The pseudorange and carrier phase models

{{MIN}} MIN · ERROR TERMS AND DUAL-FREQUENCY CORRECTION

A pseudorange is not a clean distance. It is the distance plus every delay that the signal met on its way, plus the clock errors at both ends. GNSS-R works by modelling or cancelling these terms, so we must know each one and its size.

Code and carrier observation equations

$$\rho=r+c\,(\delta t_u-\delta t^s)+I_\rho+T+M_\rho+\varepsilon_\rho$$ $$\Phi=r+c\,(\delta t_u-\delta t^s)-I_\Phi+T+\lambda N+M_\Phi+\varepsilon_\Phi$$
\(r\): geometric range (with orbit error). \(\delta t_u, \delta t^s\): receiver and satellite clock errors. \(I\): ionosphere. \(T\): troposphere. \(N\): integer ambiguity. \(M\): multipath. \(\varepsilon\): noise. Both equations also hold satellite and receiver hardware delays; we fold them into the clock terms here.

The ionosphere is dispersive: it delays the code and advances the carrier by the same amount. The troposphere is not dispersive: it delays both equally, at all GNSS frequencies.

$$I_\rho=I_\Phi=\frac{40.3\;\text{TEC}}{f^2}\ \text{m}\qquad(\text{TEC in electrons/m}^2,\ 1\ \text{TECU}=10^{16})$$
At L1, 1 TECU = 0.162 m. At L5, 1 TECU = 0.291 m.

Code and carrier diverge

Over a satellite pass the slant TEC changes with elevation. The code range grows by \(+I\) and the carrier range shrinks by \(-I\). Code minus carrier is therefore \(2I + \lambda N\) plus noise and multipath. This drift is why carrier smoothing of the code must be done with care.

$$\rho-\Phi=2I-\lambda N+(M_\rho-M_\Phi)+(\varepsilon_\rho-\varepsilon_\Phi)$$

Dual frequency: remove the ionosphere

$$\rho_{IF}=\frac{f_1^2\,\rho_1-f_5^2\,\rho_5}{f_1^2-f_5^2}=2.261\,\rho_1-1.261\,\rho_5$$ $$\rho_{GF}=\rho_5-\rho_1=(\gamma-1)\,I_1,\qquad \gamma=\Big(\frac{f_1}{f_5}\Big)^2=1.793$$
The iono-free combination removes 99.9 % of the ionosphere (the first-order term). Everything that is not dispersive stays: range, clocks, troposphere. The noise grows: with equal noise on both signals, \(\sigma_{IF}=\sqrt{2.261^2+1.261^2}\,\sigma=2.59\,\sigma\).

All seven HERON signals sit on only two carriers (1575.42 and 1176.45 MHz). So one pair of coefficients works for GPS, Galileo and BeiDou.

For GNSS-R: the direct and reflected paths go through the same ionosphere, so the iono term cancels in their difference with no dual-frequency step. Part 10 shows which terms do not cancel.

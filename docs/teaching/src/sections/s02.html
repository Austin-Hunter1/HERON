What a working GNSS needs

{{MIN}} MIN · REQUIREMENTS FOR THE TRILATERATION SYSTEM

The forest worked because we knew where the towers were, we could tell the chimes apart, and they rang at a known time. Scale that up to a world-wide, all-weather, always-on system and you get this list. Every item becomes a feature of the signal.

Know where the transmitters are
Each satellite broadcasts its own orbit (ephemeris) and clock correction inside its navigation message. The ground segment uploads new values about every 2 hours.
→ Navigation message · Part 05
Tell the transmitters apart
All GPS satellites send on the same frequency. Each one has its own pseudo-random noise (PRN) code. The receiver separates them by correlation: code division (CDMA), not tone division (FDMA).
→ PRN codes · Part 04
Measure again and again
The code repeats every 1 to 10 ms, so the receiver gets a new range at every repeat. The message repeats in frames of seconds, so a receiver can start at any time.
→ Repeating structure · Parts 03, 07
Know what time it is
Atomic clocks on each satellite keep system time. The message stamps the time of transmission. The receiver clock error is the fourth unknown, so we use four or more satellites.
→ Time of week + 4th satellite · Parts 01, 05
Work in any weather
L-band (1 to 2 GHz) goes through cloud and rain with little loss. The ionosphere delay goes as 1/f², so two frequencies let the receiver measure it and remove it.
→ L1 + L5 · Part 09
Hear a signal below the noise
A satellite 20 000 km away sends about 50 W. At the antenna the signal is about 20 dB below the thermal noise. The code spreads the signal, and correlation collects it back with 30 to 40 dB of gain.
→ Correlation gain · Parts 04, 06
HERON adds one more
For reflectometry we receive the same satellite twice: the direct path and the path that bounced off the water. Both receivers must share one clock so that the difference between the two paths is clean.
→ Shared 10 MHz + PPS clock board · Part 10

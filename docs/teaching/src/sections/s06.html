Acquisition: search for code delay and Doppler

{{MIN}} MIN · SEARCH SPACE, DETECTION THRESHOLD, COARSE TO FINE

Before the receiver can track a satellite, it must find it. It does not know the code delay (1023 options for C/A) or the Doppler (about ±5 kHz). So it tests every pair, and it accepts a pair only when the correlation is above a threshold that noise seldom crosses.

The cell test

Each cell is one code delay \(\hat\tau\) and one Doppler \(\hat f_D\). The receiver wipes off the carrier at \(\hat f_D\), correlates with the code at \(\hat\tau\), sums coherently for \(T\), then adds \(K\) of these powers.

$$S(\hat\tau,\hat f_D)=\sum_{k=1}^{K}\Big|\sum_{n\in T_k}x[n]\,c[n-\hat\tau]\,e^{-j2\pi \hat f_D nT_s}\Big|^{2}$$ $$\mathbb E\,|z|^2\propto \underbrace{\Lambda^2(\delta\tau)}_{\text{code}}\;\underbrace{\operatorname{sinc}^2(\delta f\,T)}_{\text{Doppler}}\;\tfrac{C}{N_0}T+1$$
The code response is a triangle 2 chips wide. The Doppler response is a sinc with first nulls at \(\pm1/T\). So the Doppler bin spacing must be about \(1/(2T)\). A longer \(T\) gives more gain but more Doppler bins.
$$P_{fa,\text{cell}}=Q_K(\gamma)=e^{-\gamma}\sum_{i=0}^{K-1}\frac{\gamma^i}{i!},\qquad P_{fa,\text{cell}}\approx \frac{P_{fa}}{N_\text{cells}}$$
With noise only, \(S\) is a sum of \(K\) unit exponentials (power normalised to the noise). Pick the threshold \(\gamma\) from the false-alarm rate you accept over the whole search.

Coarse, then fine

Coarse: short \(T\), wide bins, whole search space. It is fast, and it finds the peak to within half a bin and half a chip.

Fine: a longer \(T\) around the coarse peak only. The Doppler response narrows (left plot), so the receiver can use bins 10 times smaller. Then it fits a parabola through the three code samples nearest the peak (right plot).

$$\hat\delta=\frac{y_{-1}-y_{+1}}{2\,(y_{-1}-2y_0+y_{+1})}\;\text{bins}$$
The tracking loops need the Doppler to within about a third of the PLL/FLL pull-in range and the code to within the DLL spacing (Part 07).
